# Chick Buck

A fried chicken brand concept website with light and dark themes, animated steam, a responsive menu, and a browser-local shopping bag.

Serve this directory with any static web server. For GitHub Pages, publish the `main` branch from `/ (root)`.

Ordering and prices are illustrative. No payments are collected and no orders are submitted. Theme and bag preferences are saved only in the visitor's browser.

Built with HTML, CSS, and JavaScript. Food imagery was generated for this concept. Fonts are Barlow Condensed and DM Sans via Google Fonts, with system fallbacks.
